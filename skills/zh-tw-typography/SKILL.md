# 繁體中文標點與排版

中文排版的錯多半不是「寫錯字」，是**鍵盤上順手打了英文標點**。這一類可以機械判定，不需要讀懂內容。

分三級：**確定錯誤**（改了沒有爭議）、**建議**（多數情況該做）、**視情況**（看語境）。

## 確定錯誤

| 錯誤 | 正確 | 說明 |
| --- | --- | --- |
| `,` 中文句子裡 | `，` | 半形逗號 |
| `.` 中文句子結尾 | `。` | 半形句號 |
| `:` 中文句子裡 | `：` | 半形冒號 |
| `;` 中文句子裡 | `；` | 半形分號 |
| `!` `?` 中文句子 | `！` `？` | 半形驚嘆號問號 |
| `...` 或 `。。。` | `……` | 省略號是六點，佔兩格 |
| `--` 或 `—` 單個 | `——` | 破折號佔兩格 |
| `"..."` 中文引號 | `「...」` | 台灣標準用「」 |
| `『...』` 當外層 | `「...」` 外層、`『...』` 內層 | 內外有別 |
| `()` 包中文 | `（）` | 括號跟著內容走 |

## 建議

**中英文之間加空格。** 這是業界慣例，不是強制規範（W3C clreq 仍在討論[空白量](https://github.com/w3c/clreq/issues/717)），但中文圈子普遍這樣排：

```
使用 Python 3.12 執行     ✅
使用Python3.12執行        ⚠ 可讀性差
```

**例外**：標點前後不加。

```
（Python）        ✅
（ Python ）      ❌
```

**數字與中文單位之間**，台灣習慣不加：`3個`、`5天`、`100元`。但跟英文單位要加：`3 kg`。

## 視情況

- **書名號**：《》用於書名、篇名、歌名。不要用來強調。
- **頓號**：「、」用於列舉。最後一項前不加「、」。
- **分號**：句子內部並列成分用「；」，但能用句號斷開時優先斷開。
- **刪節號的位置**：`……` 後面不加句號。
- **引號內外的標點**：完整引句，句號在引號內；片段引用，句號在引號外。

## 用法

```bash
python scripts/check_type.py 檔案.txt
```

輸出：

```
  3:12   [半形逗號] 「,」 → ，
  5:28   [省略號] 「...」 → ……
  7:4    [破折號] 「--」 → ——
  9:15   [引號] 「"」 → 「」
```

`--json` 輸出結構化結果，`--strict` 連建議級也列入。

## 不做的事

**不自動改。** 排版錯的位置常常在引號內、程式碼裡、URL 裡，自動替換會弄壞東西。這個工具只標位置，改不改由人決定。

**不管中英文間空格是否 100% 一致。** 那是風格，不是錯誤。只在密集缺失時提示。
