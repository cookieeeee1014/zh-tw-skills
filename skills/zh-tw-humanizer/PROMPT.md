# 提示詞：繁體中文去 AI 味

這份文件的用途：把「AI 腔」的可測量特徵，翻譯成模型真的能執行的指令。

---

## 核心原理

模型寫作時選的是**對最廣泛讀者都成立**的表達，所以處處安全、處處平滑。人寫作只對**一個具體讀者**說話，因此會有跳躍、省略、忽然短一句。

去 AI 味不是換幾個詞，是**把「為所有人寫」改成「為這個人寫」**。

推論出一條硬規則：

> **保留的每一句，都必須給讀者一個原本沒有的資訊。**

做不到的句子就刪。這一條砍掉的廢話比所有詞表加起來都多。

---

## 指標 → 動作對照表

**這是整份文件最重要的一段。** 左邊是數字，右邊是模型能執行的動作。

| 測到的現象 | ❌ 模型做不到的指令 | ✅ 可執行的指令 |
| --- | --- | --- |
| 句長節奏 0.349（平滑） | 「讓句長有變化」 | 「每個長句（25 字以上）後面接一句 10 字以內的短句。全文至少 3 處」 |
| 抽象詞 6.2/千字 | 「降低抽象程度」 | 「每個抽象名詞（賦能、閉環、落地、生態）後面必須跟一個具體數字或例子；跟不出來就整句刪」 |
| 高級同義詞偏多 | 「用樸素的詞」 | 「把『撰寫→寫、運用→用、嘗試→試、具備→有、從事→做、達成→做到』全部換掉」 |
| 三件套 | 「不要強湊三點」 | 「列舉有幾項寫幾項。兩項、四項、五項都可以」 |
| 空洞收尾 | 「結尾要有力」 | 「刪掉最後一段如果它只是重述。以最後一個具體事實作結」 |
| 假深刻開場 | 「開頭要吸引人」 | 「第一句必須是事實或數字，不能是背景鋪陳」 |

**規則**：寫提示詞時，凡是模型無法在一次生成中計算的東西（標準差、密度），都必須轉換成**具體的、可數的、位置明確的**動作。

## 可直接使用的提示詞

```
改寫以下文本，讓它讀起來像人寫的繁體中文。保留所有事實、數字、專有名詞，不要新增任何原文沒有的資訊。

依序做這四件事：

1. 清地區用詞（最優先，一個錯就全毀）
   把簡體大陸用詞改成台灣說法：
   信息→資訊、軟件→軟體、網絡→網路、內存→記憶體、默認→預設、加載→載入、屏幕→螢幕、打印→列印、服務器→伺服器、賬號→帳號
   生活詞：互聯網→網際網路、米（長度）→公尺、創可貼→OK繃、吊瓶→點滴

2. 刪
   刪掉：總而言之、綜上所述、希望以上內容對你有幫助、在這個快速變化的時代、隨著…的發展、作為一個 AI、我理解你的需求、讓我們一起來、值得注意的是、研究表明（若無來源）。
   原則：每一句都要說出一件具體的事。說不出來的整句刪除，不要改寫。

3. 具體化
   抽象名詞後面必須跟數字或例子：提升效率→從 40 分鐘縮到 5 分鐘；優化體驗→少點兩次、少填三個欄位。
   跟不出具體內容的，刪掉那句話。

4. 調節奏
   長句（25 字以上）之後接一句短的（10 字以內），全文至少 3 處。
   連續三句結構相同時，改掉其中一句的開頭。
   讀出聲——如果每句都一樣長，回頭再改。

不要動：
- 引文、標題、專有名詞內部的字
- 技術文件、法律文件、操作步驟裡的「首先」「其次」（那是正確結構）
- 具體的、不尋常的細節（真實地址、奇怪引述）
- 混合情緒、未解決的張力、真誠的旁白
- 作者自己加的限制詞（或許、通常、在我看來）——這些是人寫作的痕跡

輸出：改寫後全文 + 變更清單（按上面四類，說明改了什麼、為什麼）。
```

## 自檢清單（改完後跑一次）

- [ ] 有沒有任何簡體大陸用詞？（最優先）
- [ ] 隨便挑三句，每句是否都說出一件具體的事？
- [ ] 有沒有連續三句長度相近？
- [ ] 抽象名詞後面有沒有數字或例子？
- [ ] 最後一段是否只是重述前面？（是就刪）
- [ ] 有沒有「首先…其次…最後」出現在不該出現的地方？
- [ ] 讀出聲，聽起來像人在講話還是像在念稿？

## 判定的證據強度（避免過度矯正）

不同破綻的可信度不一樣。維基百科《Signs of AI writing》的原則是：**破綻的權重等於「細心作者刻意這麼寫的頻率」——越少見，越可信。**

**單獨出現就足以判定：**

- 「不是 X，而是 Y」的否定平行
- 「首先…其次…最後」的三段式（在非技術文件裡）
- 「作為一個 AI」「我理解你的需求」
- 簡體大陸用詞（A 級）

**要成群才算數（單個不算）：**

- 破折號 —— 很多編輯也用
- 高級同義詞 —— 正式文體本來就會用
- 過渡詞（因此、然而、此外）—— 人類也這樣寫，維基明確說「不是強信號」
- 模糊限定（可能、或許、通常）—— **這是人寫作的標誌，不是 AI 的**

**不能當指標的（維基列為 ineffective）：**

- 文法完美
- 正式／學術腔（要看具體用詞，不是整體風格）
- 沒有引用來源
- 文白夾雜

## 中英模式對照

英文的 AI 破綻在中文長什麼樣：

| 英文模式 | 中文對應 |
| --- | --- |
| Not X but Y | 不是…而是…、不只…更是…、與其說…不如說… |
| Rule of three | 首先…其次…最後；第一…第二…第三 |
| Avoidance of copulatives（避免 is/are） | 扮演著…的角色、具有…的意義、起到…的作用 |
| Stiff synonyms（authored/relocated/utilized） | 撰寫、運用、嘗試、具備、從事、建構 |
| Shallow -ing riders | …，展現了…／體現了…／象徵著…／反映了… |
| Em dash | ——（中文用破折號） |
| Inflated significance | 具有重要的意義、標誌著…的里程碑、開啟了新篇章 |
| Vague attribution | 研究表明、專家指出、業內人士認為（無來源） |
| Rule-of-three adjectives | 高效、穩定、可靠（三個形容詞連用） |
